# 🚀 GrowthElite – Premium LinkedIn Growth Landing Page

## 📌 Project Overview

**GrowthElite** is a responsive, single-page landing page developed as part of a **web development workshop**. It features a LinkedIn profile audit form, responsive UI, Google Sheets integration, and a payment flow, providing hands-on experience in frontend development and external service integration.

### 🌐 Live Version

The project is also deployed online:

🔗 https://3-d-webinar-jet.vercel.app/

## ✨ Features

* 📱 **Fully Responsive Design** – Works across desktop, tablet, and mobile devices
* 🎨 **Modern UI** – Clean and professional landing page design
* 📝 **Audit Form** – Collects name, email, and phone number
* 📊 **Google Sheets Integration** – Form data is sent to Google Sheets using Google Apps Script
* 💳 **Payment Integration** – Includes a ₹1 payment option through Cashfree
* ⚡ **Vanilla JavaScript** – Handles form validation and submission
* 🔄 **Smooth Scrolling** – Easy navigation between sections
* 🖥️ **No Server Setup Required** – Can run locally as an HTML file

## 🔧 How It Works

1. 👤 User enters their **Name, Email, and Phone Number**
2. 📤 The form sends the information to a **Google Apps Script**
3. 📊 The submitted information is stored in **Google Sheets**
4. 💳 Users can proceed to the **₹1 Cashfree payment**
5. 📩 After submission, the user receives a message about the audit link
