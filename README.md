# GrowthElite - Premium LinkedIn Growth Landing Page

🌐 https://3-d-webinar-jet.vercel.app/

## Project Description
A responsive, single-page landing page built with HTML/CSS/JavaScript that converts visitors into audit customers. 
Features a professional design with a conversion-optimized form and integrated payment flow

Key Features

🎨 Fully Responsive Design - Optimized for desktop, tablet, and mobile
📝 Google Sheets Integration - Form submissions auto-saved via Google Apps Script
💳 Payment Integration - Direct link to Cashfree payment gateway (₹1 audit offer)
🚀 No-Server Required - Works as local file (file://) without server setup
✨ Modern UI - Clean, professional design with smooth animations

How It Works

Users fill out form (Name, Email, Phone)
Data submitted via GET request (no-cors) to Google Apps Script
Responses automatically saved to Google Sheets "Responses" tab
Users can proceed to ₹1 payment or receive audit link via email

Tech Stack

HTML5
CSS3 (Responsive, no external dependencies)
Vanilla JavaScript (Fetch API)
Google Apps Script (Backend)
Google Sheets (Database)
Cashfree (Payment Gateway)
